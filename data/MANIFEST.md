# NMDesc input data

`ship/` holds 36 files, 242 MB, largest 55 MB. Every file is under GitHub's
100 MB per-file limit. Full listing with sizes in `ship_inventory.csv`; the classification
of all 99 referenced file names is in `classification.csv`.

Inputs are located by **file name**, at any depth under the data root, by `data_file()` in
`gene level_v5/lib/paths.R`. The root defaults to this `data/` directory and is overridden
by `NMDESC_DATA`:

```bash
export NMDESC_DATA=/path/to/data
Rscript run_analysis.R
```

fetched before it runs. `genemap2.txt` is referenced only in a documentation example in
`paths.R`; none of the seven steps reads it.

## `human (1).txt`

The PIONEER human interaction and interface table, used for the PPI-overlap feature at gene
level and the PPI annotation at variant level. The copy in `ship/` has five columns and
146,138 data rows:

| column | content |
|---|---|
| `uniprot1`, `uniprot2` | the two partners |
| `source` | evidence source, e.g. `PDB`, filtered on in `disease genes/snv/main.R` |
| `interface_residues1`, `interface_residues2` | interface residue positions, one list per partner |

These are the columns `run_ppi_overlap_analysis()` and `variant_pfam_ppi()` read. The
upstream table additionally carries `sequence1` and `sequence2`, the full protein sequence
of each partner repeated for every pair, which account for most of its 165.9 MB; an
analysis needing them can fetch the upstream file and point `NMDESC_DATA` at it.

## Optional inputs

`GTEx_Analysis_v10_RNASeQCv2.4.2_gene_median_tpm.gct` feeds the tau tissue-specificity
feature in step 6 and is read with `must = FALSE`; the column is NA without it.
